#AWS #Service #Integration
### EventBridge

Fully managed serverless event bus service for connecting applications using event-driven architecture. Routes events from AWS services, custom applications, or SaaS integrations to targets like Lambda, SNS, or SQS. Supports event filtering, transformation, and scheduling for automated workflows.

### How It Works
- Events flow through an event bus; each AWS account gets a default bus plus custom buses.
- Rules on a bus match incoming events against event patterns and route matches to one or more targets.
- Event sources include AWS services (via CloudTrail and service-level events), custom applications, and partner SaaS event sources.
- EventBridge Scheduler runs rate and cron expressions to trigger targets on a schedule.
- The schema registry captures event structures and generates code bindings for applications.

### Key Features
- Content-based event filtering with pattern matching on event fields.
- Input transformation to reshape events before delivery to targets.
- Archive and replay of events for reprocessing and auditing.
- API destinations plus native targets such as Lambda, SNS, SQS, and Step Functions.
- Dead-letter queues for target invocation failures.
- Cross-account and cross-region event bus routing with resource-based policies.

### Common Use Cases
- Decoupling microservices that respond to business events such as orders or signups.
- Automating infrastructure responses, e.g., reacting to CloudTrail API calls or EC2 state changes.
- Scheduled jobs using cron and rate expressions (e.g., nightly maintenance).
- Integrating SaaS products such as Salesforce and Zendesk into AWS workflows.
- Feeding event-driven data pipelines into Lambda, Kinesis, or data stores.

### Pricing & Limits
- Billed per event published to a custom or partner event bus and per rule match.
- Events generated by AWS services on the default bus are typically not billed, keeping basic automation low cost.
- API destinations and invocations of targets such as Lambda follow their own pricing.
- Pricing scales with event volume; simple schedules and routing stay low cost.

### Related Services

- [[Lambda]]: Processes events routed by EventBridge.
- [[SNS]]: Receives EventBridge events for notifications.
- [[SQS]]: Queues EventBridge events for processing.
- [[CloudWatch]]: Monitors EventBridge metrics and logs events.
- [[Step Functions]]: Orchestrates workflows triggered by EventBridge.
- [[Kinesis]]: Streams high-volume event data for processing.
- [[S3]]: Emits events from object operations.
- [[CloudTrail]]: Supplies management API events as a routing source.
- [[API Gateway]]: Exposes event-driven APIs that feed the event bus.
- [[SES]]: Delivers event-triggered email notifications.
- [[Secrets Manager]]: Provides secrets used by event-driven functions.

### Related Concepts

- Event-Driven Architecture: Applications respond to events in real-time.
- Event Bus: Centralized hub for routing events to multiple targets.
- Event Filtering: Routes specific events based on patterns or rules.
- SaaS Integration: Connects third-party applications (e.g., Salesforce) to AWS workflows.
- Event Replay: Re-processes archived events for recovery or testing.
- Schema Registry: Stores and evolves event schemas.
