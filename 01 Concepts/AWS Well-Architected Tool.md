### AWS Well-Architected Tool

AWS Well-Architected Tool reviews your workloads against the six Well-Architected Framework pillars — operational excellence, security, reliability, performance efficiency, cost optimization, and sustainability. It generates milestone-based recommendations to improve architecture.

### How It Works
- Define a workload and answer a structured questionnaire for each pillar.
- Answers are scored against best-practice lenses and AWS-defined high-risk patterns.
- The tool flags risks and generates improvement plans with prioritized actions.
- Reviews are saved as milestones, capturing the architecture state at a point in time.

### Key Features
- Guided questionnaires for all six pillars.
- Risk and issue tracking per pillar with remediation guidance.
- Milestone snapshots to show improvement over time.
- Sharing and collaboration via AWS teams and workloads.
- Integration with AWS Trusted Advisor and the Well-Architected review process.

### Common Use Cases
- Running periodic architecture reviews for production workloads.
- Preparing for the AWS Well-Architected Framework certification or exam.
- Tracking improvement plans across multiple workloads in an organization.
- Justifying architectural changes with documented risk findings.

### Pricing & Limits
- The tool is free to use; only AWS usage of reviewed workloads incurs charges.
- The number of workloads per account and region may be limited.
- Deep-dive reviews and workshops are offered through [[AWS Support]] and AWS Professional Services.
