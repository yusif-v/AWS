### SaaS

Software as a Service (SaaS) is a cloud service model where fully functional software is delivered over the internet, with the provider managing everything from infrastructure to application updates. Customers consume the software through a browser or API without installing, maintaining, or scaling anything themselves.

### How It Works
- The provider hosts the application and underlying infrastructure in its data centers.
- Customers access the software via a web interface, mobile app, or API.
- Updates, patching, and scaling are applied centrally by the provider.
- Billing is typically subscription-based, per user or per feature.

### Key Features
- No installation or infrastructure management required.
- Automatic updates and centralized maintenance.
- Accessible from any device with an internet connection.
- Predictable subscription pricing and flexible plans.
- Provider-managed security, availability, and compliance baselines.

### Common Use Cases
- Using email, collaboration, or productivity suites.
- Adopting CRM, ERP, and other business applications quickly.
- Replacing on-premises software to reduce maintenance burden.
- Scaling user access without managing hardware or licenses.

### Pricing & Limits
- Priced per user per month or by feature tier, rather than by infrastructure.
- Customization is limited to what the provider exposes.
- Customers retain responsibility for their data and user access under [[Shared Responsibility Model]].
